# CodeCollab – Real-Time Collaborative Code Editor

[GitHub Repo](https://github.com/AbhiTyagi17/Realtime-Editor)

##  About The Project

**CodeCollab** is a full-stack real-time collaborative code editor built with the MERN stack. It allows multiple developers to write HTML, CSS, and JavaScript simultaneously in a shared session, similar to Google Docs but for code. Users can see live previews of their work instantly.

This project demonstrates my expertise in WebSocket architecture, real-time state synchronization, and full-stack JavaScript development.

##  Key Features

-  **Real-time Collaboration** – Multiple users can edit the same file simultaneously using Socket.io.
-  **Live Presence** – See who else is currently in the room.
-  **Live Preview** – Instant visual feedback for HTML/CSS/JS inside the built-in output pane.
-  **Responsive Design** – Works seamlessly on desktop and tablet devices.
-  **Low Latency** – Optimized WebSocket connections for sub-100ms sync.

##  Built With

- **MongoDB** – (Planned for persistence, currently in-memory)
- **Express.js** – Backend API server
- **React.js** – Frontend user interface (Hooks & Context API)
- **Node.js** – Runtime environment
- **Socket.io** – Real-time bidirectional event-based communication
- **CodeMirror** – In-browser code editor
- **Tailwind CSS** – Utility-first CSS framework
